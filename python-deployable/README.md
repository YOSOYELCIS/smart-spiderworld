# Standalone SpiderWorld — Python

An independent, terminal-based Python translation of SpiderWorld. It has no CoBlop, browser, Firebase, or third-party package dependency.

## Run

```bash
python3 spiderworld.py
python3 spiderworld.py --level 7
```

Use `help` in the game for the programming language. Programs end with `END`:

```text
REPEAT 2 { F }
END
```

The game supports the twelve SpiderWorld concepts: movement, turns, rocks, goal checks, red/blue/green painting, repeats, repeat-until-wall, and named procedures.
